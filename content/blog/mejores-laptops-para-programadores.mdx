## ¿Qué necesita un programador en su laptop?

El desarrollo de software exige **potencia, RAM abundante y una buena pantalla**. A diferencia de un estudiante promedio, un programador corre múltiples aplicaciones simultáneamente: IDE, navegador con decenas de pestañas, terminal, Docker, bases de datos locales y más.

En República Dominicana, cada vez más desarrolladores eligen laptops reacondicionadas certificadas por la relación calidad-precio inmejorable.

## Especificaciones ideales para programar

### Procesador
- **Mínimo**: Intel Core i5 / AMD Ryzen 5 (12va/13va gen o Ryzen 5000/6000)
- **Recomendado**: Intel Core i7 / AMD Ryzen 7 o Apple M2/M3
- **Para trabajo pesado** (compilación, VMs, contenedores): i7/i9 H-series o M3 Pro/Max

### RAM
- **16GB**: Mínimo absoluto para desarrollo moderno
- **32GB**: Estándar profesional (Docker + IDE + Browser + DB)
- **64GB**: Para trabajo con ML, video, múltiples VMs

### Almacenamiento
- **512GB SSD NVMe**: Mínimo
- **1TB+**: Recomendado (los proyectos, node_modules, Docker images ocupan mucho)

### Pantalla
- **14-16"** con buena densidad de píxeles
- **Relación 16:10** (más espacio vertical para código)
- **Alta resolución** (2.5K/3K/4K) para texto nítido
- **Buen brillo y cobertura sRGB** si haces frontend

### Teclado
Crítico para programadores. Busca:
- Recorrido decente (1.5mm+)
- Layout estándar (teclas de flecha completas, Home/End/PgUp/PgDn)
- Retroiluminación

## Preguntas frecuentes

**¿Mac o Windows/Linux para programar?**
Depende de tu stack. iOS/macOS development → Mac obligatorio. Web/backend/cloud → Linux/Windows nativo o WSL2 funciona perfecto. Muchos devs usan ThinkPad con Linux (Fedora, Ubuntu, Arch, NixOS).

**¿16GB RAM es suficiente en 2026?**
Para web/frontend: sí. Para backend, Docker, mobile, data: **32GB es el nuevo estándar**. La RAM no se puede actualizar en la mayoría de laptops modernas (soldada).

**¿Importa la GPU para programar?**
Solo para: ML/AI, desarrollo de juegos, video editing, múltiples monitores 4K. Para desarrollo web/backend estándar: **GPU integrada moderna (Intel Arc, AMD 780M, Apple M-series) sobra**.

**¿Puedo usar una laptop gaming para programar?**
Sí, tienen buen CPU/GPU/RAM, pero: pesadas, mala batería, ventiladores ruidosos, pantallas orientadas a gaming (alto refresh, no necesariamente buena precisión de color), teclados "gamer". **Mejor business laptop** (ThinkPad, Latitude, MacBook, Zenbook).
