## ¿Qué define a una "laptop de trabajo" en 2026?

No es lo mismo que gaming ni diseño. Aquí **la productividad manda**:

1. **Teclado excelente** (escribes 8h/día)
2. **Batería real 10h+** (reuniones, café, avión, corte de luz)
3. **Puertos completos** (HDMI, USB-A, USB-C/TB4, RJ45, SD) → **sin dongles**
4. **Pantalla 16:10** (más líneas de código/Excel/email)
5. **Seguridad** (Huella, IR Face, TPM 2.0, Kensington, vPro/AMD PRO)
6. **Durabilidad** (MIL-STD-810H, chasis metal, bisagras probadas)
7. **Soporte empresarial** (garantía on-site, drivers estables, fleet management)

## Checklist antes de comprar para tu equipo

- [ ] **Teclado**: ¿Layout ES/LATAM? ¿Retroiluminación? ¿Travel 1.5mm+?
- [ ] **Pantalla**: ¿16:10? ¿300+ nits? ¿100% sRGB? ¿Antirreflejo mate?
- [ ] **Puertos**: ¿2x TB4/USB4? ¿HDMI 2.1? ¿USB-A 3.2? ¿RJ45? ¿SD? ¿Kensington?
- [ ] **Batería**: ¿57Wh+ (14") / 70Wh+ (16")? ¿Carga 65W+ USB-C? ¿Rapid Charge?
- [ ] **Seguridad**: ¿Huella en botón power? ¿IR Face (Windows Hello)? ¿TPM 2.0? ¿vPro/AMD PRO? ¿Kensington?
- [ ] **Conectividad**: ¿WiFi 6E / WiFi 7? ¿WWAN 4G/5G slot (opcional)?
- [ ] **Garantía**: ¿3-5 años on-site disponible? ¿Extensión accidental damage?
- [ ] **Gestión**: ¿Intune/Autopilot/SCCM/Jamf ready? ¿Drivers pack disponible?

## Preguntas frecuentes

**¿ThinkPad T14s vs T14?**
- **T14s**: Más delgado (1.2kg), RAM soldada (1 slot), menos puertos, mejor pantalla estándar, más premium.
- **T14**: Ligeramente más grueso (1.4kg), **RAM 1 soldada + 1 slot SODIMM (hasta 48GB)**, más puertos (RJ45 nativo), mismo teclado, mejor cooling.
- **Para flotas: T14** (upgradable, reparable). **Para ejecutivos móviles: T14s**.

**¿AMD Ryzen PRO vs Intel vPro?**
- **Ryzen PRO 7040/8040 (7840U/8840U)**: Mejor eficiencia (batería 15-20% más), iGPU 780M potente, menos calor, mejor multi-thread.
- **Intel Core Ultra 100/200 (155U/165U/256U/266U)**: NPU para AI local, Quick Sync superior, TB4 nativo, mejor single-thread, vPro maduro.
- **2026: AMD gana en battery life y thermals. Intel gana en AI features y ecosystem enterprise.**

**¿16GB RAM es suficiente en 2026?**
- **Office 365 / Web / Teams / Zoom / ERP web**: **Sí, 16GB OK**.
- **VMs locales / Docker / Bases de datos / IDE pesado / Muchas pestañas**: **32GB mínimo**.
- **En ThinkPad T14 (no s) y Latitude 5000/7000: agregas 16GB por RD$3,500 después**.

**¿Vale la pena pantalla OLED en laptop trabajo?**
- **Pros**: Contraste infinito, negros puros, 100% DCI-P3, texto nítido, menos fatiga visual en modo oscuro.
- **Contras**: Burn-in riesgo (bajo en 2024-2026, pero real con UI estática 8h/día), brillo pico menor (400 nits vs 500+ IPS), consumo batería +10-15%.
- **Veredicto**: **Sí si >50% tiempo en modo oscuro / terminal / código. No si apps claras estáticas (Excel, SAP, CRM) todo el día.**

**¿Garantía on-site vale la pena?**
**Sí para flotas >10 laptops**. Un técnico viene a tu oficina en 24-48h. Evita logística de envío, downtime del empleado. Costo ~RD$3,000-5,000/laptop/3 años. **Para 1-5 laptops: carry-in (tú la llevas) está bien.**

**¿Windows 11 Pro vs Home?**
**Siempre Pro** para trabajo: BitLocker, Group Policy, Remote Desktop Host, Hyper-V, Windows Sandbox, Domain Join / Entra ID, Assigned Access, kiosk mode, update control. **Home no sirve para empresa.**
