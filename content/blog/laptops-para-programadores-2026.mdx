Programar no requiere la GPU más potente, pero sí los specs correctos. Un developer con la laptop equivocada pierde horas en builds lentos, Docker que no carga, y pantallas que cansan los ojos. Esta guía te dice qué buscar realmente.

## Los 3 Specs que Importan para Programar

### 1. RAM: 16GB es el mínimo, 32GB el ideal

| Uso | RAM necesaria | ¿Por qué? |
|-----|--------------|-----------|
| VS Code + navegador + terminal | 8GB funciona | Básico |
| **Docker + VS Code + DB** | **16GB mínimo** | Docker consume 2-4GB |
| Android Studio + emulador | 16GB justo | Emulador: 2-4GB |
| **Multi-proyecto + Docker + Navegador** | **32GB ideal** | Cero swapping |
| Machine Learning / IA local | 32GB+ | Modelos grandes |

> **Realidad en RD 2026**: Si usas Docker (casi todos los devs), 8GB no es suficiente. 16GB es el mínimo real. 32GB es el sweet spot.

### 2. CPU: Multi-core importa para builds y Docker

| Uso | CPU recomendado | ¿Por qué? |
|-----|----------------|-----------|
| Frontend (React, Vue, Next.js) | i5/Ryzen 5 suficiente | Compilación rápida |
| **Backend (Node, Python, Java)** | **i7/Ryzen 7 recomendado** | Builds paralelos |
| **Docker + microservicios** | **i7-13700H/Ryzen 7 7840HS** | Múltiples contenedores |
| Mobile (Android Studio) | i7/Ryzen 7 | Emulador + IDE |
| DevOps/Cloud | Ryzen 7 / i7 | Terraform, Ansible, K8s |

### 3. Pantalla: 14" 1080p+ IPS, ideally 16:10

| Aspecto | Mínimo | Ideal |
|---------|--------|-------|
| Tamaño | 14" | **14-16"** |
| Resolución | 1080p | **1200p+ (16:10)** |
| Panel | IPS | **IPS 100% sRGB** |
| Matte vs Glossy | Cualquiera | **Matte (menos reflejos)** |
| Touch | No necesario | Útil para tablets 2-in-1 |

**16:10 vs 16:9**: Con 16:10 ves **~11% más líneas de código** en vertical. Para programar, la diferencia es significativa.

## Docker: El verdadero test de RAM

Si usas Docker (compose con 3-5 servicios), esto es lo que consume tu sistema:

| Componente | RAM promedio |
|-----------|-------------|
| VS Code + extensiones | 500MB-1.5GB |
| Chrome (10-20 tabs) | 2-4GB |
| Docker Desktop | 2-4GB (configurable) |
| Cada contenedor | 256MB-1GB |
| Node.js / Python | 200-500MB |
| Base de datos local | 512MB-2GB |
| **Total típico** | **8-16GB** |

> **Tip**: En Docker Desktop, limita RAM a 6-8GB (Settings > Resources). No dejes que Docker se coma toda la RAM.

## macOS vs Windows para Programar en RD

| Aspecto | macOS (MacBook) | Windows (ThinkPad, Dell, etc.) |
|---------|----------------|-------------------------------|
| **Terminal** | Unix nativo (zsh) | WSL2 = casi igual |
| **Docker** | Funciona (limitado en M1-M3) | Docker Desktop nativo |
| **IDE** | VS Code, JetBrains, Xcode | VS Code, JetBrains, Visual Studio |
| **iOS dev** | ✅ Obligatorio | ❌ Solo con Mac remoto |
| **Gaming** | ❌ Prácticamente nada | ✅ Cualquier juego |
| **Precio** | RD$55,000+ | **RD$28,000+** |
| **Build quality** | Premium | Variable (ThinkPad = premium) |

**En 2026**: WSL2 en Windows prácticamente iguala a macOS para development. La ventaja real de Mac es iOS dev y batería.
